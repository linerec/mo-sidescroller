# 스토리 바이블 (템플릿)

> 이 문서는 "무엇을 만들 것인가"를 코드보다 먼저 정하기 위한 틀입니다. 채워가면서 `story/chapters.js` 의 `beats` 와 동기화하세요.

## 한 줄 컨셉
> 이름도 기억도 잃은 채 숲에서 깨어난 "모"가, 세상 곳곳에 흩어진 기억 조각을 모으며 자신이 잠근 문의 정체를 알아가는 이야기. *(데모용 가안)*

## 세계관 규칙 (플레이와 직결되는 것만)
- 기억은 물리적 "조각"으로 존재한다 → 수집 아이템 = 스토리 진행 화폐
- 잊힌 것들은 "덩어리"가 되어 떠돈다 → 적의 존재 이유
- 등불은 기억을 잠시 붙잡는다 → NPC/체크포인트의 상징

## 막(챕터) 구조 — 긴 호흡 설계
각 챕터는 **질문 하나**를 던지고, 마지막 스테이지에서 **부분적 답**과 **더 큰 질문**을 남깁니다.

| 챕터 | 질문 | 새 메커닉 | 마지막 비트 | 스테이지 수 |
|---|---|---|---|---|
| 1장 잊혀진 숲 | 나는 누구인가 | 이동/점프/대화/레버 | 열쇠는 내가 잠근 문의 것 | 3~4 |
| 2장 | | 새 능력 1 | | |
| 3장 | | 새 능력 2 / 첫 보스 | | |
| … | | | | |

## 스테이지 비트 시트 (스테이지마다 복사)
```
스테이지 id:
제목 / 부제:
분위기(env):               예) 새벽, 안개, 푸른 톤
플레이어가 아는 것 / 모르는 것:
진입 컷씬:                 (있으면 3줄 이내로)
목표(objective) 변화:      A → B → C
퍼즐:                      무엇을, 왜(이야기적 이유)
적:                        종류, 배치 의도
수집품:                    기억 조각 n개 — 각 조각이 암시하는 것
대화:                      NPC / 표지판 / 독백 — 진행 상황별 변형
클리어 조건:
클리어 후 남는 플래그:      (다음 스테이지가 참조)
```

## 플래그 명명 규칙
- `met_<npc>` 첫 만남 · `asked_<topic>` 선택지 기록 · `<puzzle>_open` 퍼즐 해결 · `saw_<thing>` 트리거 방문
- 자동 생성: `got:<uid>` 아이템 획득, `item:<id>` 인벤토리 개수, `cleared:<stageId>` 클리어
